# Project: Custom Functional Interface & Lambda Expressions

A short project demonstrating the creation and implementation of a custom functional interface in Java. Instead of relying solely on built-in solutions from the `java.util.function` package (like `Function` or `Consumer`), this project shows how to define a custom behavior contract and instantiate it on the fly using lambda expressions.

## 🛠 Under the Hood (Technical Details)

This project leverages the following core Java mechanisms:
* **Custom Functional Interface:** A custom interface annotated with `@FunctionalInterface`, containing exactly one abstract method (SAM Type - *Single Abstract Method*).
* **Generics:** The interface uses a generic type `<T>`, allowing for the flexible passing of objects of any class during implementation (e.g., a custom `Cat` class, `Double`, `Object`), securing the code at compile-time against the *Raw use of parameterized class* warning.
* **Type Inference:** Interface implementations are created as anonymous objects using lambda expressions. The Java compiler automatically maps the argument structure and function body to the method defined in the interface.
* **Auto-boxing / Unboxing:** Utilizing built-in Java mechanisms for automated, safe conversion between primitive types (e.g., the `int` result from the `.length()` method) and object types (`Integer`).

## 📂 Project Structure

### 1. `InterfaceExercise1<T>` (Contract)
A functional interface enforcing strict rules for implementation:
* **Input:** Takes a text (`String`), an integer (`Integer`), and any target object defined by the generic type (`T object`).
* **Output:** Returns an integer (`Integer`).

### 2. `ImplInterfaceExercise1` (Logic and Execution)
The main startup class containing two separate implementations (*behavior variants*) of the above interface, realized via lambdas:
* **Implementation 1 (Sum of values and lengths):** A lambda taking 3 parameters. It extracts the length of the passed `String`, adds the exact value of the passed `Integer`, and finally adds the length of the string generated by the `toString()` method of the target object.
* **Implementation 2 (Stream API Filtering):** An advanced lambda utilizing the standard **Stream API** (`.chars().filter().count()`). It filters letters based on specific conditions and sums the final results, performing safe casting from the `long` return type to `int` to prevent data loss.

## 🚀 How to run it?
This project requires no external dependencies (Zero-dependency). Just compile the code using any standard IDE (IntelliJ IDEA, Eclipse) and run the `ImplInterfaceExercise1` class. The results of the operations performed by the lambdas will be printed directly to the standard console output.
